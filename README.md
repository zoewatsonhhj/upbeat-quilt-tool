# upbeat-quilt-tool



折腾中的小玩具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/upbeat-quilt-tool.git
cd upbeat-quilt-tool
cargo build --release
```
